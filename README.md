# Лабораторна робота №14. Досяжність у графі

- **Дисципліна:** Алгоритми та структури даних
- **Група:** ІПЗ-3/1
- **Мова програмування:** C#

## Що реалізовано
- **`VisitAll(g, start)`:** обхід графа у ширину (`BFS` через чергу) від стартової зупинки з множиною відвіданих вершин `visited` для захисту від зациклення.
- **`Reachable(g, from, to)`:** перевірка досяжності цільової зупинки на основі результату `VisitAll`.
- **`FindPath(g, from, to)`:** відновлення шляху між зупинками через словник предків `parent` з подальшим розгортанням у правильному порядку (або повернення порожнього списку, якщо шляху немає).

## Контрольні значення (обхід від «Центр»)
- Відвідано вершин (`visitAll("Центр")`): `6`
- Недосяжних вершин: `2` (`Гай`, `Міст`)
- Шлях «Центр» → «Озеро»: `Центр → Парк → Вокзал → Озеро` (`3` ребра)
- Шлях «Центр» → «Стадіон»: `Центр → Ринок → Стадіон` (`2` ребра)
- Шлях «Центр» → «Міст»: `[]` (порожній список)
